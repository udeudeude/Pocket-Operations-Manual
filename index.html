Instrument status

Select a sound or tap a pad.

Guided lessons validate the actions you take on the virtual instrument. Use the device itself to practice.

Free play

Tap a pad to trigger sound. Tap WRITE to program the 16-step pattern. Tap ▶ to run the sequencer. A function key arms a one-handed combination with the next pad.

Keyboard: number row 1–8 plays pads 1–8, Q–I plays 9–16, Space toggles playback, W toggles write mode.

Recording studio

Record up to 8 seconds into one of 15 sound slots. Recordings are retained in this browser using IndexedDB, when available. Audio is approximate rather than hardware-identical.

Microphone permission is requested only when recording.

Save / restore

Pattern export does not contain recorded audio. Audio data-transfer backups to a physical PO-35 are not implemented.
