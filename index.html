Two-button combinations

Tap a function button, then a numbered pad. The selected function stays armed for one pad press, making combinations usable with one hand on an iPhone.

Tap a pad to hear a sound. Tap WRITE to edit steps.

Audio requires a tap to unlock. Microphone access requires HTTPS and permission.

Quick reference

SOUND + 1–15: choose recording. SOUND + 16: drum voice. PATTERN + 1–16: choose pattern. FX + 1–8: voice. FX + 9–15: effect. BPM + 1–16: volume. WRITE: toggle step editing. PLAY: start/stop. REC + 1–15: record to slot (prototype uses the separate microphone button).

Knob A/B bank changes when FX is tapped. Tempo cycles 80, 120, 140 BPM when BPM is tapped. This prototype implements simplified audio, not the original firmware's vocal synthesis or data transfer.
